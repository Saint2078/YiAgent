## 定稿观感（已确认「好完美」）

- 深色底 + 高对比分区色（G1–G5）
- 双螺旋持续旋转；粒子沿链流动（可开关）
- **等位直接嵌在螺旋链上的基因珠**（非外侧飘节点）
- 悬停基因珠 / 分区出详情；左侧分区标签、右侧等位列表（可滚动）

## 演示基因组

- 主题：**ASE 前线部署工程师（FDE）**（`ase_fde`）
- 规模：G1–G5 共约 **40** 个等位（每槽 1 个当前表达，其余备选/对照）
- 表达链（亮色大珠）= 当前基因；对照链（灰珠）= 备选 / 反模式
- 默认旋转/粒子关闭（省电）；可手动开启
