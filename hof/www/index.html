这是什么

名人堂是 YiAgent 社区的公共基因组评分档案：各地自部署的 factory 在跑完筛选/进化后， 自愿（opt-in）把评分卡上报到这里，汇聚成跨用户的排行榜与等位基因边际表现。 冷启动不再从零进化——从排行榜下载冠军基因组 JSON，直接当作 factory evolve/start 的 seed。

数据口径

  • 榜单分数一律为 community 社区自报分，未经项目方复跑验证。
  • 同 gene_hash 的多次上报按样本量 n 加权合并 mean/sdv，再做贝塔收缩（m=5, prior=75）。
  • 上榜门槛 min_n：累计鉴定样本量不足的不进榜。
  • 等位文本含 rubric / 评分标准关键词的上报直接拒收（灌评分标准等于作弊）。

如何 opt-in 上报

  1. 在本地 YiAgent config 中显式打开 ship.enabled = true（默认永远关闭）。
  2. 可用 --dry-run 先查看"如果打开会上报什么"，payload schema 公开可查。
  3. 进化 run 结束后，客户端自动把终代冠军与各代冠军的评分卡 POST 到 /api/hof/submit。
  4. 贡献者标识为本地随机匿名 ID，可随时重置；绝不上报 API key、原始 prompt 或模型输出全文。
  5. 企业内网可自建私有名人堂：把 SHIP_URL 指向内网实例即可。
